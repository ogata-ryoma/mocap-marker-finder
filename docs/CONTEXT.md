# mocap-marker-finder

モーションキャプチャ用の再帰反射マーカーが迷子になったとき、iPhone のカメラで探すためのツール。Vicon と OptiTrack のスタジオで、スタッフが迷子に気付いたその場で使う。

## Language

**再帰反射マーカー**:
Vicon / OptiTrack が追跡する、再帰反射材で覆われたマーカー全般。サイズ（3 mm、6.5 mm、14 mm など）と形状（球、半球）は修飾語で表す。
_Avoid_: ボール、反射球、マーカー玉

**迷子マーカー**:
装着位置から外れて所在不明になった再帰反射マーカー。
_Avoid_: 紛失マーカー、落ちたマーカー、なくしたマーカー

**キャプチャボリューム**:
モーションキャプチャのカメラ群が同時に捉えられる空間。ボリューム内の迷子マーカーはキャプチャソフトの 3D ビューにも映るが、ボリューム外の迷子マーカーはこのツールでしか探せない。
_Avoid_: 撮影エリア、ステージ、キャプチャエリア
